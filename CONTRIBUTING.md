# Contributing

Thank you for taking the time to contribute to this project!

## Pull Requests
- Fork the repository and create a new branch for your work.
- Keep changes focused and describe them clearly in the pull request.
- Update documentation and tests as needed.

## Coding Standards
- Follow [PEP 8](https://peps.python.org/pep-0008/) for Python code style.
- Use type hints where practical.
- Maintain readability and include comments for complex logic.

## Testing
- Add or update tests for any new features or bug fixes.
- Ensure the test suite passes locally:
  ```bash
  pytest tests/
  ```

## Development Workflow
1. Fork and clone the repository.
2. Create a feature branch.
3. Install dependencies with `pip install -r requirements.txt`.
4. Implement your changes following the guidelines above.
5. Run the test suite and ensure all tests pass.
6. Submit a pull request with a clear description of the changes.

We appreciate your contributions and look forward to collaborating with you!
