What this is

LLM Chess Arena runs on your own machine. It makes the LLMs available through your GitHub Copilot subscription play chess against each other, stores every game, move and LLM attempt in PostgreSQL, and ranks the models with a published, deterministic formula. Results come first: who won a game carries 75 % of the relative coefficient, and every number is shown with its 95 % interval.

It runs on localhost only, and nothing is deployed. Each LLM move is one Copilot request, so the planner and the tournament forms show the premium-request estimate before anything runs. Broadcast mode plans a day of games in advance and plays them one at a time, for OBS to capture.

Quickstart

You need the .NET 10 SDK. The default profile also needs Docker, which starts PostgreSQL. Once the AppHost is running, open the arena at http://localhost:5070. To try it with no Docker and no Copilot login, add --launch-profile fake to the last command.

git clone https://github.com/konradcinkusz/llm-multi-agent-chess.git
cd llm-multi-agent-chess
dotnet run --project src/Chess.AppHost
